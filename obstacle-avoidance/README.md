# 障碍物避障系统

此目录是与仓库中 `versions/` 主运输、循迹系统平行的独立避障系统。

STM32CubeIDE 工程位于：

```text
obstacle-avoidance/XXXv3/
```

主要功能：

- OpenMV 蓝色障碍物识别与方位数据接收
- JY61P IMU 航向反馈
- 四路超声波距离检测
- 四轮编码器与左右轮速度闭环
- 世界航向正负90°范围内的视觉避障
- 转向卡住检测及制动重试
- 蓝色块面积较小时优先进入绕行前进
- 前进时执行“左蓝右避、右蓝左避”

`Debug/` 和其他本地编译输出由仓库根目录的 `.gitignore` 排除。
